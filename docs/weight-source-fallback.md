# 权重来源逻辑已升级

当前默认爱站模式已改为每天独立采集并同时保存两站权重，不再只在爱站失败时请求站长权重。详细数据库结构、历史迁移、接口与部署步骤见 [双源每日快照](dual-source-snapshots.md)。

顶层兼容结果仍优先选择当日有效爱站数据，其次选择当日有效站长数据，两站都无效则 `weight_valid=false`。APPPC 排名、分类、注册人、邮箱、到期日继续由独立站长补充任务维护。

本次不修改 `weight_change_notifier.py`。现有通知仍读取顶层选中结果，并按原有的“目标日与前一自然日、双方有效且同来源”规则比较。保存两站数据不等于启用了两站各自的通知；后续通知方案另行调整。
